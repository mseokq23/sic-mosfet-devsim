# 강건성 사전 예측 (v1.3 — 변형 시뮬레이션 실행 전에 기록·커밋)

목적: RQ1의 다중 온도 이득(평균 −36%, W_JFET −53%)이 채택한 모델 가정(채널 이동도 온도지수 γ = +1,
정적 Q_it,eff)과 폐쇄세계 평가에 얼마나 의존하는지 확인한다. 이 문서는 robustness-batch 실행 전에 커밋한다.

## 고정 규칙 (결과를 본 뒤 바꾸지 않음)
- 변형(`configs/variants/`): γ ∈ {0, −1} (기준 +1), 423 K에서 |Q_it,eff| 10%·30% 감소(300 K에서 0, 온도에 선형).
- 423 K만 재계산(300 K 물리는 동일): 풀 512점, 테스트 128점. 설계·잡음 모델(noise-v1.1)·전류 바닥·특징 추출은 동결본 그대로.
- in-model: 학습·평가 모두 변형 물리. out-of-model: 학습은 동결 기준, 평가만 변형 물리 또는 기생 직렬저항.
- 기생 직렬저항: 소자별 ρ ~ U(0.1, 0.3) mΩ·cm² (시드 2026), 드레인 측 1차 근사. R_on,sp에 더하고
  선형 영역 전류·g_m·I_D(2 V)를 보정, V_th·SS는 불변(전류 ≤ 1e-4 A/cm에서 IR 강하 무시).
- 주 지표: 테스트 128점 평균 MAE/범위(GP, nominal 잡음). 보조: 2배 잡음. S2−S1 짝지은 부트스트랩 95% CI(5,000회).
- 판정: "S2 우세 유지" = CI 상한 < 0. 수렴 실패는 개수를 보고하고 두 온도 모두 수렴한 점만 사용. 모든 시나리오를 결과와 무관하게 보고.

## 예측
- R1 (γ, in-model): γ = 0, −1 모두 S2 우세 유지. 평균 개선률은 기준(36%)보다 작고 γ가 작을수록 줄어든다.
  감소는 주로 W_JFET에서 나타나고 N_pw·Q_it 개선률 변화는 ±10%p 이내.
- R2 (Q_it(T), in-model): 두 시나리오 모두 S2 우세 유지. V_th 온도 이동에 Q_it 성분이 섞여 N_pw 개선률은 줄 수 있다(방향만 예측).
- R3 (γ, out-of-model): 평균 개선률이 in-model보다 작다. γ = 0에서는 S2 우세 유지. γ = −1은 열린 질문(방향 예측 없음).
- R4 (Q_it(T), out-of-model): 추가된 V_th 온도 이동을 N_pw 변화로 오인해 S2의 N_pw 오차가 커진다.
  −30%에서는 S2의 N_pw 오차가 S1보다 클 것으로 예측. 평균 개선률은 줄어든다.
- R5 (기생 직렬저항, out-of-model): **사전 예측 아님** — 코드 검증 중 이미 계산됨(탐색적 결과로 보고).
  nominal: S1 0.378, S2 0.261 (S2−S1 −0.117 [−0.130, −0.105]); W_JFET 0.864→0.469, N_pw 0.187→0.221, Q_it 0.084→0.093.

## 해석 규칙
- R1·R2가 성립하면 "다중 온도 이득은 검토한 가정 범위에서 유지"로 서술한다.
- R3·R4에서 S2 우세가 사라지면 "다중 온도 역추정은 온도 의존 물리의 불일치에 민감하며 보정이 전제"로 서술한다(약화된 결론을 그대로 보고).
