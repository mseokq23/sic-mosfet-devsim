## 1. 추가한 비교 (모두 사후 분석)

- **시나리오별 S1×2 비교(표 2).** 같은 물리로 학습하면 S2는 다섯 시나리오 모두 S1×2보다 작았다(기준 −17%, γ = 0 −15%,
  γ = −1 −12%, r = 0.1 −34%, r = 0.3 −62%, 짝지은 부트스트랩 CI 모두 0 미만). 다섯 가정을 섞어 학습하면 평균 오차는 S1×2와
  구분되지 않았다(−5%~+1%, CI 모두 0 포함). W<sub>JFET</sub>만 기준·r 변형에서 작은 이득(비 0.80~0.86)이 남았다.
- **기준 물리로 학습한 모델의 범위 제한 예측.** γ = 0, −1에서 0.537, 0.928 → 예측을 DOE 범위로 제한해도 0.388, 0.449.
- **같은 DEVSIM 예산에 S1×2 추가.** 120회: S1 0.127, S1×2 0.096, S2(60점) 0.085. 480회에서도 S1 0.113, S1×2 0.087.
- **시드 수준 통계(RQ2·RQ3).** 짝지은 차이의 SD 0.0026~0.0047, 검출 가능한 최소 차이(검정력 0.8) 0.0025~0.0047.
  A − U는 동등 기준(90% 구간이 ±0.0025 안)을 만족하지만 같은 조건의 1차 실행 A0 − U는 만족하지 않는다.
  A − D는 부트스트랩 CI [−0.0043, −0.0004]이지만 t 구간은 0을 포함하고(부호 뒤집기 p = 0.055) A0 − D는 차이가 없다.

## 3. 가독성

- 각 결과 문단의 첫 문장에 결론을 두고(예: “423 K 특징의 이득 가운데 약 2/3는 측정 횟수에서 나왔다.”), 근거 수치를 뒤에 둔다.
- 한 문단에 한 가지 결과만 담도록 4.1(반복 측정, 같은 예산, 원인, 잡음 상관)과 4.2(같은 물리, 틀린 물리, 모르는 물리, 직렬저항)를 나눴다.
- 긴 문장을 나누고, 시나리오별 수치는 표 2(S1×2 대비 변화와 유의성 표시), RQ3 절제 수치는 표 3으로 옮겼다.
- 서론은 배경 → 선행연구와 공백 → 연구 질문·기여 순으로 정리하고, 기여를 ①②③으로 적었다.
