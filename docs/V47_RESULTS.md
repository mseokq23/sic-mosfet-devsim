- 능동학습 환경: 같은 세션에서 다시 실행한 불확실도 정책 곡선이 논문 실행(`results/al`)과 **완전히 같다**(최대 차이 0).
  따라서 논문의 LLM 실행(A0)과 이번 원본 형식 실행(A)은 같은 환경에서 같은 조건을 두 번 실행한 것이다.

  B의 payload 60개 모두 물리 변수명 없음, C의 60회 모두 표시된 최악 변수가 실제와 다름(설계대로).
- 요약 파일은 커밋된 원자료에서 다시 계산해 같은 값이 나오는 것을 확인했다(`scripts/rq3_ablation.py`).

### 예측하지 않은 관찰
- **잡음 상관 ρ (C7c).** 두 측정의 오차가 상관될수록 반복 이득은 사라졌지만(S1×2: ρ = 0, 0.5, 0.9에서 0.086, 0.101, 0.110)
  S2는 0.072, 0.077, 0.075를 유지했다. ρ ≥ 0.5에서는 N_pw·Q_it,eff도 S2−S1×2의 CI가 0 미만이 되었다(ρ = 0.9: −0.029, −0.013).
  ρ = 0.9에서 온도차 특징을 더한 S3가 GP 오차를 더 낮췄다(0.064, S3−S2 −0.011 [−0.019, −0.004]). Ridge는 S2만으로 0.066이었다(선형 모델은 차분을 스스로 만든다).
- **직렬저항에서 반복 측정이 오히려 나빠짐.** S1×2(0.405)가 S1(0.378)보다 컸다(+0.027 [+0.017, +0.036]). 소자별 직렬저항은 두 번 측정해도
  같은 계통 오차라 평균으로 줄지 않고, 잡음이 줄어든 학습이 계통 편이를 더 크게 반영한 것으로 보인다(탐색적 해석).
- **고온 물리 불일치와의 대비.** 423 K 물리 변형은 300 K 특징을 바꾸지 않으므로 S1×2는 표 2의 모든 시나리오에서 0.086이다.
  기준 물리로 학습한 S2가 γ = 0, −1에서 0.537, 0.928로 무너지는 것과 대조된다.

### 예측하지 않은 관찰
- **같은 조건의 반복 실행 차이.** A0 − A = +0.0014 [+0.0001, +0.0027](같은 환경, 같은 조건). LLM 응답의 비결정성만으로
  조건 간 차이와 같은 크기의 차이가 생긴다.
- **A − D = −0.0023 [−0.0043, −0.0004].** 원본 형식의 LLM이 상위 20 내 무작위보다 최종 오차가 작았지만, 논문 실행 A0과 D의 차이는
  −0.0009 [−0.0027, +0.0006]이었고 라운드 1–6 평균에서는 A − D도 차이가 없었다(−0.0005 [−0.0017, +0.0009]). 반복 실행 변동과
  같은 크기이므로 결론에 쓰지 않는다.
- **행동 지표.** 최악 변수 방향 확대: A 47/60(무작위 기대 52%), B 49/60(56%). 익명화해도 행동이 거의 같았다(B는 x1–x4만 보고도 같은 전략).
  사유 코드 TEMPERATURE_CONTRAST는 A·C에서 0회, B에서 4회 쓰였다.
- **비용.** 토큰 입력/출력 A 179,590/31,968, B 150,172/20,829, C 179,655/27,715, 평균 지연 5.9, 4.7, 5.5 s.

## 원고 반영 요약 (V4.7)
- RQ1: 36% 감소를 "반복 측정 23% + 온도 고유 17%"로 분해하고, 온도 고유 이득이 W_JFET에 집중됨을 주 결과로 둔다.
  반복 이득은 고온 물리와 무관하지만 측정 오차가 상관되면 사라지고, 온도 고유 이득은 상관에 강건하지만 고온 물리가 틀리면 역전된다.
- RQ3: 절제 결과로 "LLM은 정보를 따르지만 정확도 차이는 없다"를 보이고, 같은 조건의 반복 실행 차이를 함께 보고한다.
- 사후·탐색 표기: S1×2와 RQ3 절제는 실행 전에 예측을 기록한 추가 분석(`cb3534b`), ρ·S3 관찰과 직렬저항의 S1×2 악화, A − D는 예측하지 않은 관찰.
- 선행연구와의 관계: Gupta 등(Findings of EMNLP 2025)은 실험 결과를 섞어도 성능이 변하지 않는 것을 LLM이 피드백을 쓰지 않는 근거로 보았다.
  이 실험에서는 최종 오차가 달라지지 않았는데도 선택은 표시된 정보를 따랐으므로(Q3·Q4), 성능만으로는 정보 사용 여부를 판단하기 어렵다는 점을 원고 4.4절에 적었다.
- 지면 보완(10/8): Word(Windows)에서 두 판 모두 마지막 쪽 오른쪽 단이 거의 비어 있다는 확인을 받아 측정 모델을 다시 맞췄다
  (바탕 줄 높이를 Times New Roman 이하로 둔 대체 글꼴, 본문 줄 간격 10.8 pt). 이 기준으로 반 쪽 분량을 보완했다:
  W_JFET 집중의 원인(300 K I_on 민감도 비 0.40 → 423 K 1.25, Cramér–Rao 하한 예상 46/17/18% 대 관측 36/9/8%),
  N_pw·Q_it,eff에서 이득이 없는 이유(V_th 온도 이동 −10.9 mV < 독립 잡음 차이 14 mV, ρ = 0.9에서 4.5 mV),
  남은 오차의 물리 단위(W_JFET 약 48 nm 등), 고온 물리 불일치에서 세 변수 모두 무너짐(γ = 0: 0.665/0.681/0.266),
  RQ2 초반 학습(라운드 1–6 불확실도 − Sobol −0.0015 [−0.0029, −0.0002], 사후), 같은 입력에서 A0·A 선택 겹침 8.3/10,
  동등성 판정(A만 불확실도와 동등, C는 D와 동등), 프롬프트 지시·교차검증 누설 방지, 호출 비용, 기여와 향후 연구.
  남은 여유(같은 모델): 프로시딩 약 11줄, 심사용 약 12줄.
