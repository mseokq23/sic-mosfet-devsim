## RQ1 (nominal 잡음, 학습 = 풀 512점, 평가 = 테스트 128점)
- 추정 오차 하한(범위 대비 1σ), S1(300 K) → S2(300+423 K): Wjfet 18.4 → 7.0%, Npwell 28.4 → 16.7%,
  Qit_eff 12.6 → 7.4%. 정보가 전혀 없을 때(균일 분포) 28.9%.
- 예상 `mae_norm` 하한(≈0.8×하한, 하한이 28.9% 이상이면 중앙값 수준 ≈0.25):
  S1 — Wjfet ≥ 0.15, Npwell ≈ 0.22~0.25, Qit_eff ≥ 0.10 / S2 — Wjfet ≥ 0.056, Npwell ≥ 0.13, Qit_eff ≥ 0.059.
- 방향: 세 변수 모두 S2 < S1, 개선 폭은 Wjfet가 가장 크고 Npwell·Qit_eff는 비슷.
- S3(S2 + 온도 차이)는 S2와 정보량이 같으므로, S3−S2 차이는 모델 표현 효과로 해석.
- S1의 Npwell 3구간 macro-F1은 우연 수준(≈0.33) 근처.
