# v4.7 통제 실험 분석 계획과 사전 예측 (실행 전에 기록·커밋)

목적: 원고 V4.6a의 두 약점을 실험으로 보강한다.
1. **반복 측정 교란(RQ1).** 잡음을 온도별로 독립적으로 넣었기 때문에 S2는 같은 소자를 두 번 측정한 효과도 얻는다.
   N_pw·Q_it,eff의 개선(−28%, −27%)은 독립 2회 측정의 기대 개선(1 − 1/√2 ≈ 29%)과 거의 같다.
   → 300 K를 두 번 측정한 통제(S1x2)와 비교해 **온도 고유 이득**만 분리한다.
2. **RQ3 귀무 결과의 해석.** "LLM = 불확실도"만으로는 LLM이 제공 정보를 쓰는지조차 알 수 없다.
   → 정보를 지우거나(B 익명화) 망가뜨린(C 정보 섞기) 조건과, LLM 없는 기준선(D 상위 20개 내 무작위)을 추가한다.

이 문서는 `exp/v4.7-controls` 브랜치에서 아래 실행 전에 커밋한다. 출력 파일의 `plan_commit`이 이 문서의 마지막 커밋을
가리킨다. 실행 전에 문서를 고치면 다시 커밋한 뒤 실행한다. 결과를 본 뒤에는 이 문서를 고치지 않고, 차이는 결과 문서에 적는다.
Git 커밋은 순서를 보여 줄 뿐 독립 기관의 사전 등록은 아니다(README의 표현 원칙과 같음).

## 계획 작성 시 이미 알고 있던 정보 (투명성)
- 논문 결과 전체(S1 0.112, S2 0.072, 변수별 비 0.47/0.72/0.73, RQ2·RQ3 수치).
- Stage A로 계산한 국소 CRB 비(설계 단계 계산, 아래 표). 시험 집합 결과가 아니다.
- 논문 LLM 실행(A0) 로그의 선택 통계: 불확실도 상위 10과의 겹침 0.63, 상위 10보다 넓은 배치 56/59회
  (같은 20개 후보에서 무작위로 10개를 고를 때의 기대 비율 약 68%, 이 계획을 만들며 처음 계산).
- 코드 점검 중 확인한 사실: 다른 CPU에서는 논문의 능동학습 곡선이 라운드 0은 같고 라운드 1부터 조금씩 달라진다
  (순방향 대리 모델의 후보 순위가 마지막 비트 수준 차이로 바뀌는 것으로 추정). GP 기반 RQ1 수치(S1 0.112275, S2 0.072011,
  CI [−0.049, −0.031], 직렬저항 0.378/0.261)는 다른 CPU에서도 정확히 재현되었다(검증 실행은 S1x2 결과를 출력하지 않음).
- S1x2, ρ 스윕, B·C·D, 같은 환경의 재실행 결과는 **아직 아무도 보지 않았다.**

## 1. 반복 측정 통제 (`scripts/repeat_control.py`)

### 고정 규칙
- 데이터: 명목 풀 512점·시험 128점(`results/pool`, `results/test`), 동결 잡음 noise-v1.1과 전류 바닥 1×10⁻¹¹ A/cm.
- 특징 집합
  - S1 = 300 K 17개, S2 = 300+423 K 34개, S3 = S2 + 온도차(논문과 같은 정의, 같은 잡음 실현)
  - **S1x2 (주 통제)** = 300 K 특징을 독립 잡음으로 두 번 실현해 평균한 17개(반복 측정의 일반적인 사용법)
  - S1x2cat (보조) = 두 실현을 나란히 붙인 34개(S2와 차원을 맞춘 통제)
- 두 번째 300 K 잡음 실현의 시드: 동결 시드 + 1000(풀 1101, 시험 1202). 학습 풀과 시험 집합 모두 두 번 측정한 것으로 둔다.
- ρ = 한 소자의 두 측정 사이의 잡음 상관(S2는 300/423 K, S1x2는 300/300 K). 표준정규 잡음 z₂ = ρz₁ + √(1−ρ²)z₂′로
  만들며 주변 분포(σ)는 바뀌지 않는다. ρ = 0이면 S1·S2·S3는 논문의 잡음 실현과 비트 단위로 같다(단위 시험으로 확인).
- 역추정 모델: GP(주), Ridge(보조). 학습·시험 구성, 모델 하이퍼파라미터, 정규화는 논문과 같다.
- 지표: 시험 128점 MAE_norm(평균과 변수별). 대비는 시험점 짝지은 부트스트랩 5,000회(시드 7, `robust.evaluate`와 같은
  재표본)의 95% CI와 평균 오차의 비.
- 실행 범위: 잡음 nominal·high × ρ ∈ {0, 0.5, 0.9} × GP·Ridge. 이차 분석으로 잡음 실현 4개를 더(GP, nominal, ρ = 0,
  실현 k의 시드 = 동결 시드 + 10000k, 반복 시드 = 그 값 + 1000). 탐색적 분석으로 기생 직렬저항(시험 데이터에만,
  `robustness.py`와 같은 ρ_s 추출)에서 S1·S1x2·S2.
- 주 분석 = **nominal, ρ = 0, GP, 동결 실현, S2 − S1x2.** 나머지는 보조·이차·탐색으로 표기한다. 모든 결과를 보고한다.
- 구조적 사실(예측 아님): 423 K 물리 변형(γ, r)은 300 K 특징을 바꾸지 않으므로 표 2의 모든 시나리오에서 S1x2 오차는
  기준값과 같다.

### 설계 단계 CRB 비 (Stage A, 6개 스칼라 특징, nominal)

| ρ | S2/S1: W_JFET | N_pw | Q_it,eff | S1x2/S1 (모든 변수) |
|---|---|---|---|---|
| 0 | 0.382 | 0.589 | 0.582 | 0.707 |
| 0.5 | 0.366 | 0.617 | 0.610 | 0.866 |
| 0.9 | 0.276 | 0.402 | 0.399 | 0.975 |

ρ가 크면 반복 측정의 이득은 사라지지만(0.975), 공유 오차가 온도차에서 상쇄되므로 S2의 국소 하한은 오히려 작아진다.
GP 역추정 모델이 이 차분 정보를 실제로 쓰는지는 열린 질문이다.

### 예측
- **C1 (주).** W_JFET: S2 < S1x2. S2 − S1x2의 95% CI 상한 < 0.
  근거: CRB 0.38 대 0.71, 실제 S2/S1 0.47.
- **C2.** N_pw, Q_it,eff: S2 − S1x2의 95% CI가 0을 포함한다(반복 측정 이상의 온도 고유 이득이 검출되지 않음).
  근거: 실제 S2/S1 0.72/0.73 ≈ 0.71. CRB(0.59/0.58)는 S2가 더 나을 수 있음을 시사하므로 확신은 중간.
- **C3.** 평균 MAE_norm: S2 < S1x2 (방향만 예측, 유의성은 예측하지 않음).
- **C4.** S1x2/S1 비가 세 변수 모두 0.62–0.82 (GP가 반복 측정 이득을 1/√2 가까이 실현).
- **C5 (보조).** high 잡음에서 C1·C2와 같은 방향.
- **C6 (보조).** Ridge에서 W_JFET의 S2 < S1x2 (방향).
- **C7 (보조, ρ).** (a) ρ = 0.9에서 S1x2/S1 비가 세 변수 모두 0.85 이상. (b) W_JFET의 S2 − S1 CI가 모든 ρ에서 0 미만.
  (c) N_pw·Q_it,eff에서 ρ에 따른 S2의 방향, S3의 이득은 예측하지 않는다(열린 질문).
- **C8 (이차).** 잡음 실현 5개(동결 포함) 중 4개 이상에서 W_JFET의 S2 − S1x2 점추정이 0 미만.
- **C9 (탐색).** 직렬저항 시험에서 S1x2 평균 ≥ 0.33이고 S2(0.261)가 S1x2보다 작다
  (소자별 직렬저항은 두 번 측정해도 같은 계통 오차라 평균으로 줄지 않음).

### 해석 규칙
- C1·C2 성립: "온도 고유 이득은 300 K에서 교란 변수(채널 이동도)와 공선인 W_JFET에 집중되고,
  N_pw·Q_it,eff의 개선은 이 조건에서 반복 측정과 구분되지 않는다."로 쓴다.
- C1 실패(CI가 0 포함): "다중 온도의 이득이 같은 횟수의 반복 측정과 통계적으로 구분되지 않았다."로 쓰고
  RQ1의 주장을 그만큼 낮춘다. 고온 물리 불일치의 위험(표 2)은 그대로 보고한다.
- C2가 S2 우세 방향으로 실패: "세 변수 모두 반복 측정 이상의 온도 고유 이득"으로 쓴다.

## 2. RQ3 절제 실험 (`scripts/run_al.py`, `scripts/rq3_ablation.py`)

### 조건 (모두 같은 Codespace·같은 세션·같은 코드 커밋에서 실행)

| 조건 | 정책 | LLM에 보이는 것 | 출력 |
|---|---|---|---|
| A | LLM, `--llm-variant named` | 논문과 같은 payload·프롬프트 | `results/al_v47/named/` |
| B | LLM, `--llm-variant anon` | 변수명 x1–x4, 소자·물리 설명을 뺀 프롬프트(`SYSTEM_PROMPT_ANON`) | `results/al_v47/anon/` |
| C | LLM, `--llm-variant shuffled` | 라운드마다 20개 후보의 (불확실도, 거리) 쌍을 무작위 순열로 바꾸고 표시 불확실도 순서로 나열, 교차검증 오차를 세 변수 사이에서 순환 이동(표시된 최악 변수는 항상 틀림). 후보 ID와 설계 좌표는 그대로 | `results/al_v47/shuffled/` |
| D | `top20_random` | (LLM 없음) 불확실도 상위 20개에서 10개를 균등 무작위 | `results/al_v47/numeric/` |
| U | `uncertainty` (+ `random`, `sobol`) | (LLM 없음) 논문과 같은 정책을 같은 환경에서 재실행 | `results/al_v47/numeric/` |

- 공통: S2 특징, RF 역추정, nominal 잡음, 시드 0–9(같은 초기 60점), 10점 × 6라운드, 후보 20개, 모델
  `claude-sonnet-5-5`, 온도 기본값, max_tokens 1024, 같은 JSON 스키마·검증기·거절 시 불확실도 대체 규칙.
- C의 섞기 난수: `default_rng([seed, round, 47])`. D의 난수: `default_rng([seed, round, 2020])`. LLM 응답과 무관하게 재현된다.
- 응답 스키마의 사유 코드 목록(예: TEMPERATURE_CONTRAST)은 조건 간 동일하게 유지한다(B에서도 바꾸지 않음).
- 논문 실행 A0(`results/al_live`)과 U0(`results/al`)은 다른 환경에서 나왔으므로 주 비교에 쓰지 않는다.
  같은 환경 여부는 U와 U0 곡선의 차이로 점검하고, A0 − A는 반복 실행 변동(환경 차이 포함)으로만 보고한다.

### 지표
- 주: 최종 라운드(120점) 평균 MAE_norm의 시드 짝지은 차이, 시드 부트스트랩 5,000회 95% CI.
- 보조: 라운드 1–6 평균 오차(학습곡선 면적에 해당)의 같은 비교.
- 동등성(보고만, 예측 없음): 90% CI가 ±δ 안이면 "동등". δ = 0.0025(논문 RQ2의 불확실도 − 무작위 효과).
- 행동(검증 통과 호출 기준, 좌표는 `configs/design_pool.csv`를 범위로 정규화):
  - 실제 불확실도 상위 10과의 겹침, 표시 불확실도 상위 10과의 겹침(A·B에서는 둘이 같음)
  - 배치의 평균 쌍간 거리가 표시 상위 10보다 큰 호출 비율
  - 표시된 최악 변수와 실제 최악 변수 방향으로 배치의 표준편차가 표시 상위 10보다 큰 호출 비율
  - 각 비율의 무작위 기대값: 같은 20개 후보에서 10개를 무작위로 2,000번 뽑아 호출별로 계산한 확률의 평균

### 예측
- **Q1 (주, 정확도).** B − U, C − U, D − U, A − U의 최종 오차 95% CI가 모두 0을 포함한다. B − A, C − A도 0을 포함한다.
- **Q2 (보조).** 라운드 1–6 평균에서도 Q1과 같다.
- **Q3 (행동, C).** 표시 상위 10과의 겹침 ≥ 0.55(표시된 숫자를 따른다), 실제 상위 10과의 겹침은 0.40–0.60
  (무작위 기대 0.50 근처).
- **Q4 (행동, C).** 표시된(틀린) 최악 변수 방향 확대 비율이 무작위 기대보다 15%p 이상 높고, 실제 최악 변수 방향 확대 비율은
  무작위 기대의 ±15%p 안이다.
- **Q5 (행동, A·B).** A의 실제 상위 10 겹침이 0.55–0.70, B는 A의 ±0.10 안. A의 "상위 10보다 넓음" 비율이 무작위 기대보다 높다.
- **Q6.** B·C의 검증 통과가 각 60회 중 57회 이상.
- **Q7 (이차, 환경 재실행).** 같은 환경의 U − random 최종 차이 점추정 < 0 (논문 RQ2 방향 유지, 유의성은 예측하지 않음).

### 해석 규칙
- Q1 + Q3/Q4 성립: "LLM은 제공된 수치와 최악 변수 정보를 읽고 그대로 따르지만(행동 변화), 후보가 이미 불확실도 상위로
  걸러져 있어 정확도 차이로 이어지지 않았다. 상위 20개 안의 무작위 선택(D)과도 구분되지 않았다."
- C가 A보다 유의하게 나쁨: LLM이 피드백을 실제로 유용하게 썼다(긍정적 결과로 보고).
- B가 A보다 유의하게 나쁨: 도메인 의미(변수명·물리 설명)가 선택 품질에 기여했다.
- Q3 실패(표시 숫자와 무관): 선택은 피드백이 아니라 좌표·다양성 휴리스틱에 따른 것으로 해석한다.
- 비교가 여러 개이므로 다중 비교 보정은 하지 않고 기술적으로 보고한다. 주 판정은 Q1이다.

## 3. 실행·보고 규칙
- 실행 순서: `bash scripts/v47_run_all.sh all` (check → control → numeric → llm → report). 절차는 `docs/V47_RUNBOOK.md`.
- 출력의 `meta`에 코드 커밋, 이 문서의 커밋(`plan_commit`), CPU·라이브러리 버전을 남긴다. 실행 전 `src/`·`scripts/`·`configs/`에
  커밋되지 않은 변경이 있으면 실행하지 않는다.
- 결과가 예측과 다르면 그대로 보고하고 차이를 `docs/V47_RESULTS.md`에 적는다. 이 문서는 수정하지 않는다.
