요약

논문 초록의 핵심 수치입니다. 오차는 세 파라미터의 절대오차를 DOE 범위로 나눠 평균한 MAEnorm(GP, 시험점 128개)이고, 범위 중앙값을 답하는 무정보 추정은 0.25입니다.

소자 특성

half-cell 2차원 단면의 단위 폭 전류(A/cm)입니다. 전달 특성은 VDS = 0.1 V, 출력 특성은 VGS = 18 V에서 계산했습니다.

RQ1 · 423 K 특징의 이득과 반복 측정 통제

S1은 300 K 특징(17차원), S1×2는 300 K를 독립 잡음으로 두 번 측정해 평균한 통제, S2는 300 K + 423 K(34차원)입니다. S2와 S1×2의 차이가 반복 측정으로 설명되지 않는 온도 고유 이득입니다.

고온 물리 가정

423 K 특성만 네 가지 물리로 다시 계산했습니다(채널 이동도 지수 γ = 0, −1과 계면전하 감소 r = 0.1, 0.3). 같은 물리로 학습하면 이득이 남고, 기준 물리(γ = +1, r = 0)로 학습한 모델을 다른 물리에 쓰면 무너집니다.

RQ2·RQ3 · 회고적 풀 평가의 표본 선택

512개 후보의 특성을 미리 계산해 두고, 정책이 고른 점만 학습에 씁니다. 모든 정책은 같은 초기 무작위 60점에서 시작해 10점씩 6회 고르고(S2 특징, RF 역추정), 시드 10개로 반복했습니다.

LLM 호출 기록

LLM(claude-sonnet-5-5)은 매 라운드 불확실도 상위 20개 후보의 설계값·불확실도 u·학습점 거리 d와 교차검증 오차를 받아 10개를 고릅니다. 결정론적 검증기를 통과하지 못하면 그 라운드는 불확실도 정책의 선택을 씁니다.
